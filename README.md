# Xgen

เว็บคำนวณแนวทางจากผลย้อนหลังจริงใน Supabase `six-digit-thai-lao` แบบอ่านอย่างเดียว

หน้าจอ Xgen Elite ใช้ธีมโชคลาภแดงทับทิม ทอง ครีม และเขียวหยก พร้อมกรอบอัญมณีและประกายแบบ CSS การ์ดเลือกตลาดจะย่อลงอัตโนมัติหลังแสดงผลเพื่อให้เห็นชุดวิเคราะห์บนมือถือได้เร็วขึ้น และแตะหัวการ์ดเพื่อเปลี่ยนตลาดได้ทันที

## หลักการ

- ดึงผลสูงสุด 30 งวดของตลาดที่เลือก โดยระบบหลักยังใช้ 4 งวดล่าสุดเหมือนเดิม
- คำนวณรูดและ WIN6 จากผลล่าสุด โดยถ้ารูดซ้ำจะใช้ตัวแรงแทนรูดรอง และถ้ายังซ้ำจะใช้เลขถัดไปใน WIN6
- แสดงเลขเบิ้ลจากสูตร HTML และเปอร์เซ็นต์เบิ้ลแบบ Walk-forward แยกตามตลาด (อย่างน้อย 15 จุด)
- เปอร์เซ็นต์ต่ำกว่า 30% เน้นรูดสลับ, 30–39% ระวังเบิ้ล และตั้งแต่ 40% เน้นเบิ้ล
- สร้างคู่ไม่เบิ้ล 15 คู่จาก WIN6
- ให้คะแนนแต่ละคู่จากความถี่ของเลขทั้งห้าหลักและจำนวนงวดที่เลขคู่นั้นอยู่พร้อมกัน
- เลือก 5 คู่ที่มีคะแนนต่ำที่สุด; เลขกลับถือเป็นคู่เดียวกัน
- คัดตัวแรง 1 ตัวจากเลขที่ปรากฏซ้ำมากที่สุดในเจาะ 2 ทั้ง 5 คู่ โดยใช้คะแนนคู่และลำดับสูตรตัดสินเมื่อเสมอ
- ปุ่มคัดลอกชุดเดียวรวมตัวแรง รูด WIN6 และเจาะ 2 ในรูปแบบเว้นบรรทัดพร้อมวางใน LINE
- ค้นหาตลาดด้วยคำบางส่วน เช่น `ลาว`, `ดาวโจนส์` หรือ `VIP` แล้วเลือกคำนวณได้ทันที

## ตั้งค่า

1. ใช้ Node.js 22 ขึ้นไป
2. คัดลอก `.env.example` เป็น `.env.local`
3. ใส่ Project URL และ Publishable key ของ Supabase
4. รัน `npm install` และ `npm run dev`

แอปอ่านผ่าน RPC `xgen_list_markets` และ `xgen_recent_results` เท่านั้น ไม่มีคำสั่งเพิ่ม แก้ไข หรือลบข้อมูล

SQL สำหรับช่องอ่านข้อมูลแบบจำกัดอยู่ที่ `supabase/xgen_read_api.sql`
