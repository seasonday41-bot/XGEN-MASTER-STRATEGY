# Xgen

เว็บคำนวณแนวทางจากผลย้อนหลังจริงใน Supabase `six-digit-thai-lao` แบบอ่านอย่างเดียว

## หลักการ

- ดึงผลล่าสุด 4 งวดของตลาดที่เลือก
- คำนวณรูดและ WIN6 จากผลล่าสุด
- สร้างคู่ไม่เบิ้ล 15 คู่จาก WIN6
- ให้คะแนนแต่ละคู่จากความถี่ของเลขทั้งห้าหลักและจำนวนงวดที่เลขคู่นั้นอยู่พร้อมกัน
- เลือก 5 คู่ที่มีคะแนนต่ำที่สุด; เลขกลับถือเป็นคู่เดียวกัน

## ตั้งค่า

1. ใช้ Node.js 22 ขึ้นไป
2. คัดลอก `.env.example` เป็น `.env.local`
3. ใส่ Project URL และ Publishable key ของ Supabase
4. รัน `npm install` และ `npm run dev`

แอปอ่านผ่าน RPC `xgen_list_markets` และ `xgen_recent_results` เท่านั้น ไม่มีคำสั่งเพิ่ม แก้ไข หรือลบข้อมูล

SQL สำหรับช่องอ่านข้อมูลแบบจำกัดอยู่ที่ `supabase/xgen_read_api.sql`
