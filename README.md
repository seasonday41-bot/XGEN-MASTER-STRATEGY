#XGEN

Xgen รุ่นใหม่ใช้ข้อมูลย้อนหลังจริงแบบอ่านอย่างเดียวจาก Supabase `six-digit-thai-lao` และมีเครื่องคำนวณเพียงระบบเดียว ไม่มี Percent, Flow, Radar, Shadow หรือ Structural Engine รุ่นเก่าค้างอยู่ใน production source

## WIN6XGEN CORE

รับผลล่าสุด `ABC-DE`

1. `F = (B + C) mod 10`
2. กรณี 3 ตัวบนเป็นตอง `AAA` ให้ใช้ `F = (A + B + C) mod 10`
3. `G = (D + E) mod 10`
4. ใช้ `F/G` เป็นแกนรูดและเป็นเงื่อนไขค้นหาเท่านั้น ไม่ใส่ `F/G` ลง Candidate Pool ล่วงหน้า
5. ค้น 5 งวดแรกตามลำดับ `FG SEARCH → F SEARCH → G SEARCH` และเปิดชุดถัดไปเฉพาะเมื่อชุดก่อนหน้ายังสร้าง WIN6 ไม่ครบ
6. ในแต่ละชุด ใช้เฉพาะงวดที่มีเลขตรงตามเงื่อนไข แล้วเก็บเลขจาก `ABC-DE` ตามลำดับที่พบ ตัดเลขซ้ำโดยคงตัวแรก ไม่เรียงใหม่และไม่ใช้ความถี่
7. ตรวจจำนวนเลขหลังเพิ่มแต่ละงวด เมื่อครบ 6 ตัวแล้วสามารถเก็บเลขใหม่จากงวดถัดไปที่ผ่านเงื่อนไขเดิมได้อีกสูงสุด 1 ตัว
8. หาก `FG → F → G` ใน 5 งวดแรกยังไม่ครบ จึงค้น 3 งวดถัดไปตามลำดับ `FG EXTRA → F EXTRA → G EXTRA`
9. ใช้เลข 6 ตัวแรกเป็น WIN6 ตัวที่ 7 เป็นเลขสำรองในวงเล็บ และหยุดทันทีเมื่อครบ 7 ตัว
10. หากครบทุกชุดแล้วยังไม่ถึง 6 ตัว ให้หยุดโดยไม่เติมเลขด้วยความถี่ คะแนน การสุ่ม เลขเงา หรือสูตรอื่น
11. เจาะ 2 และเจาะ 3 สร้างจาก WIN6 หลัก 6 ตัวเท่านั้น เลขสำรองไม่ถูกนำไปสร้างชุดเจาะ

ไม่มีการหาเลข H ไม่มีการแบ่งกลุ่ม จัดอันดับ คัดชุด หรือเติมเลขด้วยสูตรอื่นในขั้นจัด WIN การ mod 10 คงอยู่เฉพาะการคำนวณ `F/G` ด้านบน

เจาะ 2 และเจาะ 3 สร้างจากตำแหน่งของ WIN ที่เรียงแล้ว เลขกลับและเลขสลับถือเป็นชุดเดียวกัน

## SyntraX Pattern Module

Pattern เป็นชั้นแสดงสัญญาณ แยกจาก WIN6 CORE และไม่แก้ WIN6 หรือรูด

- ลำดับจำแนก 3 ตัวบน: `TRIPLE → AAB → ABB → ABA → NORMAL`
- ตรวจเบิ้ลล่าง `DD`
- ตรวจพี่น้องเฉพาะตำแหน่ง `AB`, `BC`, `DE`
- `90/09` เป็นพี่น้อง และเลขซ้ำไม่ใช่พี่น้อง
- พี่น้องออกต่อเนื่องอย่างน้อย 2 รอบ → เปิดสัญญาณเฝ้าดูเบิ้ลสำหรับรอบถัดไป
- เบิ้ลออกต่อเนื่องอย่างน้อย 2 รอบ → ติดตามพี่น้องต่อเนื่อง 5 รอบ
- เลข 3 ตัวชุดเดิมสลับตำแหน่ง หรือเลขเรียง 3 ตัวออกต่อเนื่อง → ติดตามตอง 5 รอบ
- หน้า UI แสดงเฉพาะสถานะพร้อมรอบติดตาม ไม่แสดงวิธีคำนวณหรือคะแนนภายใน

Pattern Flow เป็นสัญญาณเฝ้าดูจากประวัติ ไม่ใช่การรับรองว่าผลรอบถัดไปจะเกิดตามสัญญาณ

## Data access

หน้าเว็บเรียกเฉพาะ RPC อ่านข้อมูล:

- `xgen_list_markets()`
- `xgen_recent_results(p_market_key, p_limit)`

Publishable key ใช้ได้ใน browser; การเข้าถึงข้อมูลถูกจำกัดด้วย grants/RLS และ RPC แบบอ่านอย่างเดียว ไม่มีคำสั่งเพิ่ม แก้ไข หรือลบผลย้อนหลัง

```bash
npm run dev
```
