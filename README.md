# WIN6XGEN

Xgen รุ่นใหม่ใช้ข้อมูลย้อนหลังจริงแบบอ่านอย่างเดียวจาก Supabase `six-digit-thai-lao` และมีเครื่องคำนวณเพียงระบบเดียว ไม่มี Percent, Flow, Radar, Shadow หรือ Structural Engine รุ่นเก่าค้างอยู่ใน production source

## WIN6XGEN CORE

รับผลล่าสุด `ABC-DE`

1. `F = (B + C) mod 10`
2. กรณี 3 ตัวบนเป็นตอง `AAA` ให้ใช้ `F = (A + B + C) mod 10`
3. `G = (D + E) mod 10`
4. `H = (F + G) mod 10`
5. ใช้ `F/G` เป็นแกนรูด
6. ค้นย้อนหลังไม่เกิน 5 งวดเพื่อหางวดแรกที่มี `G+H` อยู่พร้อมกัน
7. ถ้าไม่พบ ใช้ชุดแรกที่มี `H` แล้วตามด้วยชุดแรกที่มี `G`
8. สร้าง Candidate Pool ตามลำดับ `F → G → H → เลขจากชุดย้อนหลัง` และตัดเลขซ้ำโดยคงลำดับแรก
9. เลือกชุดแรกที่มีเลขไม่ซ้ำครบ 6 ตัว ล็อก `F/G` และแบ่งได้เป็นหนึ่งในสองโครงสร้าง:
   - คู่ 2 ตัวจำนวน 3 คู่ โดยทุกคู่มีผลบวก `mod 10 = 0`
   - ชุด 3 ตัวจำนวน 2 ชุด โดยทุกชุดมีผลบวก `mod 10 = 0`
10. เฉพาะเมื่อ Candidate Pool ยังไม่ครบ 6 ตัว ให้เติม “คู่แรก” จากย้อนหลังที่ `mod 10 = 0` และเลขทั้งคู่ไม่ซ้ำ Candidate หลัก

ไม่มี fallback ขยายเลขย้อนหลังทั่วไป และไม่วนข้ามคู่แรกไปใช้สูตรอื่น

เจาะ 2 และเจาะ 3 สร้างจากตำแหน่งของ WIN6 ที่เรียงแล้วเท่านั้น เลขกลับและเลขสลับถือเป็นชุดเดียวกัน

## SyntraX Pattern Module

Pattern เป็นชั้นแสดงสัญญาณ แยกจาก WIN6 CORE และไม่แก้ WIN6 หรือรูด

- ลำดับจำแนก 3 ตัวบน: `TRIPLE → AAB → ABB → ABA → NORMAL`
- ตรวจเบิ้ลล่าง `DD`
- ตรวจพี่น้องเฉพาะตำแหน่ง `AB`, `BC`, `DE`
- `90/09` เป็นพี่น้อง และเลขซ้ำไม่ใช่พี่น้อง
- แสดง Sibling Streak และสถานะ Double Watch จาก 5 งวดล่าสุด

## Data access

หน้าเว็บเรียกเฉพาะ RPC อ่านข้อมูล:

- `xgen_list_markets()`
- `xgen_recent_results(p_market_key, p_limit)`

Publishable key ใช้ได้ใน browser; การเข้าถึงข้อมูลถูกจำกัดด้วย grants/RLS และ RPC แบบอ่านอย่างเดียว ไม่มีคำสั่งเพิ่ม แก้ไข หรือลบผลย้อนหลัง

## Local development

```bash
npm install
npm test
npm run dev
```
